# Cell Classification – Cell-line recognition from motility features

Project for the **Pattern Recognition & Machine Learning** course (A.Y. 2024/2025)  
Authors: Silvia Gialloreto, Valerio Luzi

The goal is to classify three prostate cell lines using features that describe **cell movement** (trajectories from time-lapse imaging):

| Class (`Y`) | Cell line | Type |
|:---:|---|---|
| 1 | RWPE1 | non-neoplastic (healthy) |
| 2 | LnCAP | neoplastic |
| 3 | PC3   | metastatic neoplastic |

The key goal of the analysis is to minimise the cases where a diseased cell is classified as healthy.

## Requirements

- MATLAB (developed with R2024b)
- Statistics and Machine Learning Toolbox (`fitcdiscr`, `zscore`, `tsne`, `fscmrmr`, `confusionchart`, ...)
- Classification toolbox 6.0 and PCA toolbox 1.5 by the *Milano Chemometrics and QSAR Research Group* (already included in `toolboxes/`, see http://www.michem.unimib.it)

## Usage

1. Open MATLAB in the repository root and add the data, scripts and toolbox to the path:
   ```matlab
   addpath('data', 'scripts', 'toolboxes/classification_toolbox_6.0')   % for class_gui
   % addpath('toolboxes/pca_toolbox_1.5')                              % for pca_gui
   ```
   The two toolboxes contain functions with the same names (`pca_model`, `visualize_*`, ...), so it is best to have only one of them on the path at a time (use `rmpath` to remove it).  
   `load` also searches the MATLAB path, so the `.mat` files in `data/` will be found.
2. Open a script in `scripts/` and run it **section by section** (`Ctrl+Enter`). The scripts are meant as analysis notebooks, and many sections open `class_gui` to train a model interactively.

> `tentativi2.m` and `train_e_test.m` load the dataset from an absolute path (`C:\Users\silgi\Desktop\Progetto Pattern\...`). On another computer, replace it with `load('dataset_cell_line_classification_motility_features.mat')`.

### Analysis workflow

1. **Exploration** (`train_e_test.m`, `tentativi2.m`): per-feature statistics, Kolmogorov-Smirnov normality test (the features are not Gaussian), t-SNE visualisation, correlation with the target.
2. **Preparation**: reproducible permutation (`rng(42)`), 80/20, 90/10 and 50/50 training/test splits, raw data or z-score standardisation (`FFNET.m` also uses min-max).
3. **Classifiers**
   - **LDA**: `fitcdiscr` (`tentativi.m`, `pca_simca.m`) and `class_gui`
   - **SIMCA**: built in `class_gui`. Per-class predictions are exported to `pred1.mat`, `pred2.mat`, `pred3.mat` and then evaluated with `simca.m`, which builds a confusion matrix with an extra "multiple assignment" category
   - **FFNET** (backpropagation neural network): trained in `class_gui`. True and predicted classes are exported to `reali.mat` and `predette.mat`, then `FFNET.m` computes the per-class accuracy, the unclassified samples and the error matrix
4. **Feature selection** (`pca_simca.m`): Fisher F-score, top 15 features, final choice of 8 features `[9, 13, 14, 8, 32, 15, 16, 19]` (speed, curvature and position), saved standardised in `Z_selected.mat`.

> **Note:** the `pred*.mat`, `reali.mat` and `predette.mat` files are created by exporting results from the GUI and are not included in the repository.

## Main results

| Model | Split | Test accuracy |
|---|---|---|
| LDA (39 features) | 80/20 | 83% |
| LDA (39 features) | 90/10 | 82% |
| LDA (39 features) | 50/50 | 81% |
| LDA (8 selected features) | 80/20 | 80% |
| LDA (8 selected features) | 50/50 | 78% |
| **FFNET (8 selected features)** | **80/20** | **87%** |

**Conclusions:** the best split is 80/20. FFNET and LDA stay accurate after the reduction to 8 features, which shows that the selected features are truly discriminative. FFNET is the best classifier because it least often labels a diseased cell as healthy: with the selected features, only 20 of its 73 errors fall into the healthy class, against 54 of 131 for LDA.

Details and plots in `docs/Ppt PATTERN.pptx`.
